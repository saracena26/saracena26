## ⭐ Featured Project: SQL Injection Defense & Analysis Lab

A hands-on, real-world simulation lab built to **practice and understand how SQL injection attacks behave across an actual networked environment** — and how defenders detect, analyze, and respond to them.

This project showcases my strengths in:

- **Networking:** pfSense routing, segmentation, isolated multi-VM lab  
- **Security Engineering:** Snort IDS, firewall tuning, traffic inspection  
- **Threat Detection:** Wazuh SIEM log analysis, correlation, alerting  
- **Attack Simulation:** SQLmap, Nikto, Burp Suite for realistic SQLi tests  
- **Blue Team Analysis:** Reviewing logs, analyzing flows, interpreting alerts  
- **Red Team Understanding:** Seeing how payloads move and trigger detections
